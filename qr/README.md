# qr

Ten generated QR codes land here, as SVG, filenames matching route slugs:

```
home.svg  rooftop.svg  morcha.svg  machan.svg  vehicle-checking.svg
dfmd.svg  qrt.svg  xray.svg  cctv.svg  medical.svg
```

Generated by `/ship`, step 12.

Two things that are easy to get wrong:

**Point them at dynamic short URLs, not the raw hosting URL.** A static code encodes the destination permanently. If the hosting URL ever changes, every printed laminated card at every duty point becomes dead paper. The redirect should be owned by the department, not an individual account.

**Scan-test with a real phone camera before printing.** A code that decodes in a library but not in a phone's built-in camera app is a failed code, and the automated check will not tell you.

Print at 2.5cm minimum for hand-held cards, larger for anything read at distance. Include the plain URL in small text beneath each code.
